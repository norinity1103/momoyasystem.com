# 既存サイト下層ページの再活用プラン

旧 momoyasystem.com（Studio.Design 製）に存在する下層ページのコンテンツを、現状の新サイト構造（Astro 製）にどう取り込むかの提案書。

> CMS API は認証必須で直取得不可だったため、URL スラッグ＋指示書／Geminiメモ／20期方針発表会PPTから内容を推定して整理しています。実テキスト・画像は引っ越し時にクライアントから受領 or 編集者・社長レビューで補完する前提です。

## ページ別 詳細提案

### 🥇 1. /company の強化 — 沿革タイムライン＋代表挨拶（フル版）

**追加する3つの章**

#### 1-A. 代表挨拶（フル版）
現状の400字 Letter を保ちつつ、Profile セクションの直下に **フル版の代表挨拶**（800〜1200字）を別章として追加。下層 /company に厚みを出す。

骨子（一次情報から）：
```
1段目  ─── 創業から20年の現場経験
2段目  ─── 「ものづくり」→「ものごとづくり」への業界変化
3段目  ─── 自社で職人を抱える限界（高かろう良かろう→高かろう悪かろう）
4段目  ─── 20期目の経営方針転換と、ディレクション会社としての覚悟
5段目  ─── 100年後を見据えたビジョンと、いま着手すること
署名   ─── 百々 彰彦
```

#### 1-B. 沿革タイムライン
```
2007  創業
2010  電気工事業 大阪府知事許可
2018  産業廃棄物収集運搬業 許可（02700196866）
2020  急速充電器インフラ案件 開始
2023  東京営業所 開設
2024  小池都知事 視察案件 完工（東京・電気付帯）
2025  事業継続力強化計画 認定
2026  20期目 ／ 事業方針転換（施工→ディレクション）
```
※ 年号と内容は社長の文字起こしを基に推定。**最終確定は社長レビュー必須**。

#### 1-C. SDGs取り組み
旧 /sdgs を /company 内に **「業界課題解決と社会貢献」** として統合。
```
GOAL 7  クリーンエネルギー — EV/PHV 急速充電器インフラ
GOAL 9  産業と技術革新の基盤 — 電気工事ディレクションという新職能
GOAL 11 住み続けられるまちづくり — 公共・行政視察対象案件
GOAL 12 つくる責任つかう責任 — 産廃収集運搬業許可 / VEソーシング
```

### 🥇 2. /service の拡張 — 電気工事の対応領域を Spec シート化

旧 /denki-kouji（電気工事）と /other-kouji（その他工事）の内容を、[/service](src/pages/service.astro) の末尾に **「対応領域 / Coverage」** として1セクション追加。

提案コンテンツ：

```
電気工事
  強電  ─── 受変電設備 / 動力設備 / 幹線設備
  弱電  ─── LAN・通信 / 防犯カメラ / 入退室管理
  高圧  ─── キュービクル / 高圧引込 / 自家用電気工作物の保安
  特殊  ─── EV/PHV充電器 / 太陽光連系 / 蓄電池

付帯工事
  内装  ─── 軽天・ボード / クロス / 床仕上げ
  空調  ─── 業務用エアコン / 換気 / ダクト

  メンテ ─── 店舗・住宅の電気・空調・弱電
```

—— カードではなく **Spec シート（key/value テーブル）** で羅列。Swiss-system の規範に合致。

### 🔵 7. column.momoyasystem.com の扱い

時事・政治系コラム（"政治家の帰化歴"、"パンデミック"、"ニュース速報" 等）— **本業のディレクション会社というブランドと整合しない** ため、新サイトには取り込みません。

ただし会社が発信を続けている事実は残せます。下記いずれかの選択肢：

| 案 | 内容 |
|---|---|
| A（推奨） | 取り込まない／リンクもしない。本サイトの世界観に集中 |
| B | Footer に "Editorial / Columns" として小さく外部リンク（弱め） |
| C | 別ドメインの完全切り離しを明示し、本サイトからは触れない |

A 推奨理由：B2B コンサル風サイトのブランドからの逸脱が大きく、信頼性を毀損するリスクがある。
