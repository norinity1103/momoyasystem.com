## ▼ 使い方

1. ChatGPT（画像生成可能なプラン）を開く
2. 上の「コピペ用プロンプト」を全文コピーして送信
3. 生成された画像を確認し、必要なら追加指示で微調整：
   - 「左右の対比をもっと強く」
   - 「数字をもっと大きく」
   - 「中央の矢印を太く」
   - 「日本語フォントを明朝体寄りに」など
4. 完成したら高解像度でダウンロード → 印刷会社へ入稿（A3横／フチなし推奨）

## ▼ 補足

- ChatGPT の画像生成は文字レンダリングが完璧ではないため、**日本語の長文はベクター画像生成後に Illustrator/Figma で再入力する**のがプロ仕様です。
- 完璧な印刷品質を目指すなら、**ChatGPT で構図・レイアウト案を出させ、それをデザイナー（川口様）に Illustrator で清書してもらう**フローが安全です。
- ブランド色の HEX は本文中に明記しているので、生成された画像が色ズレしていれば再生成時に「色を厳密に #1e5a9f に」と追加指示を。
