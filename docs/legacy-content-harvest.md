# 旧サイト 実コンテンツ回収結果（2026-07-29）

旧 momoyasystem.com（Studio.Design / Nuxt SPA）から**実描画後の本文**を回収した結果。

これまで [legacy-content-integration-plan.md](./legacy-content-integration-plan.md) は「CMS API が認証必須で直取得できず、URL スラッグから内容を推定」した状態だった。本書はその推定を**一次情報で置き換える**ためのもの。

## 回収方法（R006）

`wget --mirror` は index.html 1ページしか取得できなかった。旧サイトは Nuxt の SPA で、ページ遷移も画像もクライアント側で生成されるため。
そこで Playwright（Chromium）で全 URL を実描画し、全画面スクロールで遅延読込を発火させてから `innerText` と全画像 URL を抽出した。

- URL 列挙: `https://momoyasystem.com/sitemap.xml` → static 12 + dynamic 3（news / news-1 / posts は同一 3 記事）
- 回収: 全 15 ページ成功、ユニーク画像・動画アセット 75 件
